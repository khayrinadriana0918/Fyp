  1. Admin Guides
    1. Create an Administrator Account
      1. Open the SIMSAP login page.
      2. Select 'Create Account'.
      3. Enter your full name.
      4. Select administrator as the role.
      5. Enter the admin registration code that provided by an existing administrator. Please ask the existing admin for a new code if the code given already being used.
      6. Enter your email.
      7. Create a password that satisfies the password requirements.
      8. Click 'Create Account' button.

    2. Login
      1. Open the SIMSAP login page.
      2. Enter the registered email address.
      3. Enter the account password.
      4. Click enter button.

  2. System Features: System Admin
    1. View the Dashboard
      1. Select Dashboard from the sidebar.
      2. View the request overview
      3. View the most recent requests submitted by Heads of Programme.
      4. Click a request row to view its complete details.

    2. View User Profile
      1. Select User Profile from the sidebar.
      2. View personal account information.
      3. The Administrator's permanent Admin Code is displayed as part of the account information.

    3. View Notifications
      1. Click the notification icon in the page header.
      2. View notifications for new requests or changes requiring attention.
      3. Select a notification to review the request that need attention.

    4. Manage Head of Programme Requests
      1. Select Head of Programme Requests from the sidebar or click on the recent request on the dashboard.
      2. View requests submitted by Heads of Programme.
      3. Use the filter panel to search or filter requests by:
        • Request ID or title
        • Priority
        • Status
        • Category
        • Sort order
      4. Click a request to open the request details popup.
      5. Review its title, category, label, priority, description, attachment, status and submission information.
      6. Select Change Status to update the request to:
        • Pending
        • In Progress
        • Completed
        • Rejected
      7. Select Change Priority to assign:
        • Low
        • Medium
        • High
        • Urgent
      8. Click Give Feedback to provide feedback to the Head of Programme.

    5. Manage Categories
      1. Select Database Management from the sidebar.
      2. View the list of existing request categories.
      3. Use the Add Category form to create a new category.
      4. Select Edit beside an existing category to modify its information.
      5. Save the changes.
      6. Use the delete option to remove a category when appropriate.

    6. Manage User Accounts
      1. Open Database Management page.
      2. View registered user accounts.
      3. Select Edit for the required account.
      4. Modify the user's name or email address.
      5. Save the change
      6. Use the delete function when an account needs to be removed.

    7. Generate an Administrator Registration Code
      1. Open Database Management page.
      2. Select Generate Admin Registration Code.
      3. The system generates a one-time code consisting of:
        • Two uppercase letters
        • Five numbers
      4. Provide this code to the person who is authorised to create a new Administrator account.
      5. Once the code is used successfully, it cannot be reused.

  1. Head of Programme Guides
    1. Create a head of programme Account
      1. Open the SIMSAP login page.
      2. Select 'Create Account'.
      3. Enter your full name.
      4. Select head of programme as the role.
      5. Enter the staff id from the institution.
      6. Enter your email.
      7. Create a password that satisfies the password requirements.
      8. Click 'Create Account' button.

    2. Login
      1. Open the SIMSAP login page.
      2. Enter the registered email address.
      3. Enter the account password.
      4. Click enter button.

  2. System Features: Head of Programme
    1. View the Dashboard
      1. Select Dashboard from the sidebar.
      2. Choose program course code to start continue using the rest of the system features.
      3. View the request overview
      4. View the most recent requests submitted by students from your programme.
      5. Click one of the request from the row table to view its complete details.

    2. View User Profile
      1. Select User Profile from the sidebar.
      2. View personal account information.

    3. View Notifications
      1. Click the notification icon in the page header.
      2. View notifications for new student requests or updates made by the system admin.
      3. Select a notification to review the request that need attention.

    4. Manage Student Requests
      1. Select student's Requests from the sidebar or click on the recent request on the dashboard.
      2. View requests submitted by students.
      3. Use the filter panel to search or filter requests by:
        • Request ID or title
        • Priority
        • Status
        • Category
        • Sort order
      4. Click a request to open the request details popup.
      5. View requests submitted by students in the same programme.
      6. Review information such as:
        1. Request Id
        2. Student Name
        3. Student's Id
        4. Semester
        5. Title
        6. Category
        7. Status
        8. Priority
        9. Date Submitted
        10. Date Resolved(if the request status is complete.)
      7. Select Change Status to update the request to:
        • Pending
        • In Progress
        • Completed
        • Rejected
      8. Select Change Priority to assign:
        • Low
        • Medium
        • High
        • Urgent
      9. Click Give Feedback to provide feedback to the student.
      10. The student will see the updated request.

    5. Submit a Request to Administrator
      1. Select Submit Request to Admin.
      2. Fill the request form.
      3. Preview the request form before confirming it to send to the system admins.

    6. View Requests Submitted to Administrator
      1. Select My Requests on the sidebar or the My Requests button under the overview.
      2. View all requests previously submitted to the Administrator.
      3. Click a request to view its full details.
      4. View feedback provided by the Administrator.

    7. Edit a Request Submitted to Administrator
      1. Select My Requests on the sidebar or the My Requests button under the overview.
      2. Click the required request.
      3. Select Edit Form.
      4. Modify the required information.
      5. Submit the updated request.

    8. Generate Administrative Report.
      1. Select Administrative Report.
      2. Review the displayed student's requests statistics and charts.
      3. Apply the available date range when needed.
      4. Use the report to review Student request activity.
  1. Student Guides
    1. Create a Student Account
      1. Open the SIMSAP login page.
      2. Select 'Create Account'.
      3. Enter your full name.
      4. Select student as the role.
      5. Enter the student id given from the institution.
      6. Enter your email.
      7. Create a password that satisfies the password requirements.
      8. Click 'Create Account' button.

    2. Login
      1. Open the SIMSAP login page.
      2. Enter the registered email address.
      3. Enter the account password.
      4. Click enter button.

  2. System Features: Student
    1. View the Dashboard
      1. Select Dashboard from the sidebar.
      2. Choose program course code to start continue using the rest of the system features.
      3. View the request overview
      4. Review recent submitted requests and their current statuses.
      5. Click one of the request from the row table to view its complete details.

    2. View User Profile
      1. Select User Profile from the sidebar.
      2. View personal account information.

    3. View Notifications
      1. Click the notification icon in the page header.
      2. Review notifications relating to changes to submitted requests.
      3. Select a notification to review the request that need attention.

    4. Submit a Request to Head of Programme
      1. Select Submit Request to Head of Programme.
      2. Fill the request form.
      3. Preview the request form before confirming it to send to the head of programmes for the student's programme.

    5. View Submitted Requests
      1. Select My Requests on the sidebar or click on View All on the table at the dashboard.
      2. View all requests previously submitted to the head of programme.
      3. Click a request to view its full details.
      4. View feedback provided by the Administrator.
      5. Use the filter panel to search, filter or sort requests.

    6. View Head of Programme Feedback
      1. Open the required request from My Requests.
      2. Locate the Feedback section at the bottom of the request details.
      3. Read the latest feedback provided for the request.

    7. Edit a Request Submitted to Head of Programme
      1. Select My Requests on the sidebar or the My Requests button under the overview.
      2. Click the required request.
      3. Select Edit Form.
      4. Modify the required information.
      5. Submit the updated request.
